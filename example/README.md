# sucorrpilot example

This example demonstrates how to run sucorrpilot
for controlled-source seismic waveform cross-correlation.

## Directory structure

```text
example/

├── 01_raw_data/
│   └── shot_gather_raw.su

├── 02_corr_data/
│   └── shot_gather_corr.su

└── 03_control_signal/
    └── control.su

## Data description

**01_raw_data**

Input seismic data before correlation.

**02_corr_data**

Output cross-correlation result generated by SUCorrPilot.

**03_control_signal**

Pilot signal used for frequency-domain correlation.
